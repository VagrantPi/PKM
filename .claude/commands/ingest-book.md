---
description: 把一本書做成「一頁地圖 + 3–7 張工具卡」，格式照 CLAUDE.md
---

把使用者指定的書（書名或 `books/` 下的檔案）做成知識庫筆記：`$ARGUMENTS`

步驟：
0. **重複偵測（先做）**：掃 `books/`（含所有子資料夾）是否已有相同或高度相似的書。
   - **書名/作者相同 → 視為重複，直接 skip**，回報「已存在：[[書名]]（位於 …）」，不重建。
   - **主題高度重疊但確實是不同書 → 擴充而非重造**：只補這本「獨有」的工具卡，重疊概念一律交叉連結到既有卡，不製造重複工具。
   - 判斷相似：比對書名、作者、核心概念（同一本書的不同語言/版本/檔名也算重複）。不確定時先問使用者要 skip 還是擴充。
1. **定位來源**：若 `books/` 已有該書 PDF/檔案就讀它；若只有書名，先問使用者要不要提供檔案或網路資料，不要憑空杜撰。
2. **讀內容（依格式選方法，務必核對原文、勿只靠記憶）**：
   - **PDF（有文字層）**：`pdftotext book.pdf out.txt`，抽目錄與關鍵章節。
   - **PDF（掃描版，`pdftotext` 抽出 0 字）**：改用 `Read` 工具直接讀 PDF 指定頁（`pages` 參數，一次 ≤20 頁），先讀目錄頁定位章節，再讀關鍵章節。
   - **EPUB**：epub 是一包 XHTML 的 zip。`unzip -q book.epub -d dir`，讀 `*.opf`（`<dc:title>`/`<dc:creator>` 拿書名作者、`<spine>` 的 `itemref idref` 拿閱讀順序），依 spine 順序把對應 `<item href>` 的 HTML 剝標籤（`textutil -convert txt` 或 python 剝 `<...>` + `html.unescape`）串成純文字再讀。書中圖多、圖上有字時，可 `Read` 對應的 `Image*.jpg`。
   - **其他格式（mobi/azw3/txt…）**：能轉純文字就轉（有 `ebook-convert`/`pandoc` 時優先用；txt 直接讀）；真的無法抽取才回報並請使用者換檔。
   - 抽取後先讀目錄／spine 掌握全書架構，再細讀關鍵章節核對定義與金句原文。
3. **建地圖**：在 `books/書名.md` 套用 `templates/book-map.md`，寫 30 秒摘要、Layer 1–2 重點、金句。
4. **萃取工具**：挑 **3–7 個可執行的工具**，每個在 `tools/工具-名稱.md` 套用 `templates/tool.md`。
   - `triggers` 必用白話情境、3–5 個（規則見 CLAUDE.md）。
   - 「怎麼用」寫成可照做的步驟/公式。
   - **型錄書例外（如 GoF 設計模式、EIP、PoEAA、重構）**：這種「每個項目本身就是一個具名工具」的書，改成**逐項展開**——每個模式/手法一頁放 `reference/<書名>/<條目名>.md`（`type: reference`，沿用 tool.md 結構），**乾淨命名不加 `工具-` 前綴**，`name:` 用「中文 English」。**不進 `tools/`、不列首頁工具卡索引**；`tools/` 只留該書少數即用心法/快速工具。掃描版 PDF 抽不到文字時，可依該領域教科書公認定義整理（於書卡 `note:` 標明），仍不杜撰冷僻主張。
5. **雙向連結**：地圖列出 `[[工具-XXX]]`；每張工具卡 `source:` 指回 `[[書名]]`。
   - 型錄書：書卡（與 MOC）依分類列出全部 `reference` 條目；**有標準英文名的工程術語用別名連結顯示英文**——`[[觀察者模式|觀察者模式 Observer]]`，別讓列表只有中文。
6. **相關連結品質再檢查（重要）**：地圖的「## 🔗 相關」與工具卡的相關區，**只放真正有實質關係的連結**——同一概念、能互補、能對照才連；**寧缺勿濫，不要為了連而硬跟既有書籍找關聯**。每個連結附一句「為什麼相關」。判準：未來的我跳過去「真的有收穫」嗎？不行就不連；既有連結若牽強就拿掉。
7. **不要連結原始 PDF/書檔**（PDF 不會上站，會變成斷連結）。
8. **維護主題 MOC**：檢查新工具屬於哪些主題——
   - 若 `moc/` 已有對應主題頁 → 把新工具加進去（附「何時用」一句話），並維持「入口/總覽卡 → 細節卡」的層次。
   - 若某主題因這次新增而累積到約 **≥4 張**相關工具、卻還沒有 MOC → 建一頁 `moc/主題.md`（`type: moc`），並從網站首頁 `index.md` 的「主題地圖」連入。
   - 主題零星、工具不多則免。
9. **產生心智圖**：完成後呼叫 `/canvas-map 書名` 為這本書生成 Canvas 心智圖並嵌回書卡（節點連到剛建立的工具卡；型錄書則只畫到家族/分類層）。
10. **回報**：列出建立的檔案、抓到的工具、更新/新建了哪些 MOC、以及心智圖，請使用者過目。
