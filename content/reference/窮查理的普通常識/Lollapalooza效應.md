## 🎯 什麼情境該想到我

當你**要做一個重要決策，想逐項檢查自己有沒有被心理傾向誤導**，或者**看到一群聰明人做出極端的蠢事、想弄清楚為什麼**的時候。

這一頁有兩個用途：

1. **Lollapalooza 效應本身**：好幾個傾向**同時朝同一個方向作用**時，後果會變得極端。
2. **25 個傾向的總覽清單**：蒙格說，這套系統「在被当做检查清单来使用时是很有用的」。

## ⚙️ 怎麼用（逐項）

### Lollapalooza傾向

**什麼時候會冒出來**：為何會出現極端結果／多個因素同向疊加／狂熱/泡沫/崩盤

**書中全稱**：「数种心理倾向共同作用造成极端后果的倾向」。

**蒙格的核心論點**：心理學教科書裡找不到它（至少沒有系統的介紹），但它在現實中極為重要。它解釋了米爾格拉姆實驗為什麼會那麼極端，也解釋了邪教如何能用多種傾向的壓力逼人皈依——被邪教盯上的人就像巴甫洛夫的狗，抵抗力因人而異，有些人會突然崩潰，邪教把這叫做「咔嚓」（snapping）。

**為什麼心理學界忽略了它**：蒙格的初步解釋是，早期的心理學教授想用狹隘、可重複、能在校園裡進行、**一次只測試一種傾向**的實驗撐起整個學科——就像物理學忽略天體物理與所有複合效應一樣。他反諷說，研究「過度簡單的思維程序」的人，自己卻用了過度簡單的研究方法。

### 蒙格最喜歡的例子：麥道飛機的撤離測試

蒙格在講稿的問答部分自問「能不能用真實事例分析這些傾向的交互作用？」，並用這個案例回答：

**發生了什麼**：政府要求飛機撤離測試要貼近現實。麥道在昏暗的機庫裡、離水泥地約 20 英尺高的機艙、用不結實的橡膠滑梯，找老年人扮演乘客。**早上**的測試造成 20 人重傷，而且超時未通過。**下午**再測一次，又失敗了，又有 20 人重傷，其中一人終身癱瘓。

**蒙格逐項對照清單的分析**：

| 步驟 | 作用的傾向 |
|---|---|
| 必須通過測試才能賣飛機 | 獎勵超級反應 |
| 趕快決定測試方式 | 避免懷疑 |
| 過度忠實地執行政府「要貼近現實」的要求 | 權威錯誤影響 |
| 計畫定了就照做 | 避免不一致 |
| 員工感到不安，但看到別人都沒反對 | 社會認同 |
| 忽略早上失敗所提供的反面證據 | 確認偏見（避免不一致的延伸） |
| 像賭徒急著扳平，下午再賭一次 | 被剝奪超級反應 |

**讀法**：沒有任何一個人是壞人，也沒有任何一個決定單獨看起來是瘋狂的。**是七個傾向同時朝同一個方向推**，結果造成 40 人重傷。

### 講稿中其他的組合案例

| 組合 | 結果 |
|---|---|
| 被剝奪超級反應 + 避免不一致 | 意識形態造成的極端認知障礙；耗盡好資產去救爛投資 |
| 社會認同 + 被剝奪超級反應 | 拍賣會上出價過高 |
| 社會認同 + 誘因 | 紐約警局的集體腐敗（「謝皮科症候群」） |
| 社會認同 + 妒忌 + 被剝奪 | 兩個小孩搶一塊小木板，而周圍明明還有很多 |
| 誘因 + 維持現狀 + 稟賦效應 + 被剝奪 | 許多波克夏股東從不賣或送出任何一股 |
| **多種傾向朝好的方向** | **戒酒組織**：讓社會認同、公開承諾等一起對抗酒癮——這是 Lollapalooza 的正面用法 |

### 蒙格舉出的十個「心理學知識發揮作用」的例子

蒙格強調，這些傾向好處可能多於壞處，所以不能也不該被消除；但正確理解並運用它們，可以避免災難。他列出的例子：

1. 卡爾·布勞恩的溝通規則：講清楚何人、何時、何地、因何故、做何事；
2. 飛行員用模擬器訓練；
3. 戒酒組織的制度；
4. 醫學院的臨床訓練方法；
5. 美國制憲會議的規則：絕對保密、最終投票前都不記名、會議結束前可以隨時重投、整部憲法只投一次；
6. 「祖母的規矩」式的激勵；
7. 哈佛商學院強調決策樹；
8. 嬌生公司類似「驗屍」的做法：回頭檢視已完成的併購，比較當初的預測與實際結果；
9. 達爾文刻意對抗確認偏見；FDA 據此要求新藥研究使用雙盲試驗；
10. 巴菲特對公開拍賣的原則：別去。

**這十個例子的共同點**：都是**用制度或程序**來抵消心理傾向，而不是靠個人的意志力。

### 怎麼把清單用在工程決策上

1. **重大決策前**（技術選型、重寫系統、延期或上線的決定）：逐一掃過上面 25 項，問「這一項現在有沒有在推我？」
2. **特別注意同方向的組合**：如果發現三個以上的傾向**都在推向同一個結論**，那個結論要特別懷疑——這就是 Lollapalooza 的訊號。
3. **事後檢討時也用**：把事故時間線中的每個決策點，對照清單找出當時作用的傾向（見 [[工具-無指責事後檢討]]）。麥道的分析就是這樣做的。
4. **設計制度抵消它**：像蒙格的十個例子一樣，把對策寫進流程（review 檢查清單、事前驗屍、反方角色），而不是只提醒大家「要小心」。

## ⚠️ 注意 / 什麼時候不適用

- **蒙格自己承認清單有重疊**：他在問答中說，清單確實有重複、有重疊，也可以用其他方式排列；但對心理學這種軟科學，進一步精煉反而會降低實用性。
- **知道越多，越不準**：蒙格指出一個悖論——人們對這套系統了解得越多，它描述的行為就越不真實，而這正是它能防範壞結果的價值所在。
- **道德界線**：蒙格說，用這些知識操縱別人以圖私利，既是道德錯誤，也不明智——因為聰明人發現後會反過來憎恨你。
- **米爾格拉姆實驗的「六種傾向」**：蒙格說可以用清單看出六種，但原文只點名了其中之一（社會認同），這裡不補寫他沒有列出的部分。
