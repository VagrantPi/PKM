## 🎯 什麼情境該想到我

當你**評價自己、自己的決定、自己擁有的東西**，或者**面對損失**的時候。

| 傾向 | 一句話 | 典型後果 |
|---|---|---|
| [[#自視過高傾向]] | 高估自己，以及屬於自己的一切 | 面試看走眼、稟賦效應 |
| [[#過度樂觀傾向]] | 想要什麼，就相信什麼 | 估算過度樂觀 |
| [[#被剝奪超級反應傾向]] | 失去的痛苦遠大於得到的快樂 | 為了扳平而加碼 |

## ⚙️ 怎麼用（逐項）

### 自視過高傾向

*Excessive Self-Regard Tendency*　**什麼時候會冒出來**：高估自己的能力/決定／過度偏愛自己的東西／團隊都覺得自己在平均之上

**蒙格的核心論點**：人會高估自己，也會高估自己的配偶、孩子、物品，以及自己已經做出的決定（**稟賦效應**）。人還偏愛和自己相似的人——這讓不好的團體自我複製，越來越糟。

蒙格還提到「**托爾斯泰效應**」：罪犯並不認為自己很壞，而且會替自己**可以改變**的糟糕表現找藉口。

**書中的案例**：
- 瑞典 **90%** 的司機認為自己的駕駛技術高於平均。
- **自選號碼的彩票**比隨機配號的彩票賣得好——人高估了自己挑的號碼。
- **面試**：蒙格擔任學術招聘委員會主席時，說服大家**不面試**，直接錄取書面資料最優秀的人。他也認為惠普因為面試印象而選擇卡莉·菲奧莉娜擔任執行長，是一個糟糕的決定。
- 一個偷糖果的孩子（後來成為南加大音樂學院院長），他父親對他說：「儿子，你还不如想要什么就拿什么，然后在每次这么做的时候，都把自己称为小偷。」——讓他無法再替自己找藉口。

**對策**：
- **看輕面試印象，看重過往的實際表現**。
- 對個人：承認「能改卻不改、只找藉口」是品德問題。
- 對組織：建立唯才是用、要求嚴格的文化；開除最糟的不守規矩者。
- 最根本的方法：評價自己、親友、財產和行為時，「强迫自己要更加客观」。

他也提醒另一面：「千万别低估那些高估自己的人。」——自信偶爾也會促成成功。

**在工程團隊裡的樣子**：
- **面試**：口才好、氣場合的候選人容易被高估；結構化面試、實際的程式題和工作樣本比「聊得來」可靠。
- **「我的程式碼沒問題」**：對自己寫的程式碼比對別人的寬容 → 這正是 code review 與自動化測試存在的理由。
- **自己設計的系統特別難放棄**（稟賦效應）。

### 過度樂觀傾向

*Overoptimism Tendency*　**什麼時候會冒出來**：計畫總是低估時間成本／賭博/創業盲目樂觀／忽略明顯風險

**蒙格的核心論點**：古希臘演說家德摩斯梯尼說：「一个人想要什么，就会相信什么。」即使沒有處於痛苦之中，人也會過度樂觀——這和 [[追求一致與逃避不適#避免痛苦的心理否認|心理否認]] 不同，後者是為了逃避痛苦。

**書中的案例**：興高采烈地買彩票；有人相信「刷卡付款、送貨到府」的雜貨店，會取代許多有效率的現金自取超市（在當時的條件下，它們並沒有）。

**對策**：透過學習，**習慣性地運用費馬與帕斯卡的機率論**。蒙格說，演化給我們的經驗法則不夠用——就像打高爾夫球必須學習新的握桿與揮桿方法，不能靠本能。

**在工程團隊裡的樣子**：
- **軟體估算**幾乎系統性地過度樂觀。對策是用機率而不是單一數字（見 [[工具-估算的藝術]] 的 PERT 與信心區間）。
- 「這次改動很小，應該不會出問題」→ 所以跳過測試。
- 用**過去的數據校準**：把過去的估算和實際時間比一比，比「這次我會更小心」有效。

### 被剝奪超級反應傾向

*Deprival-Superreaction Tendency*　**什麼時候會冒出來**：損失比獲得更痛／捨不得認賠／差一點到手更抓狂

**蒙格的核心論點**：「失去造成的伤害比得到带来的快乐多得多。」而且，**差一點就得到卻落空**，感覺就像被奪走了已經擁有很久的東西。人因此會小題大作。

**書中的案例**：
- 帳戶裡有 1000 萬美元的人，因為錢包裡的 300 美元丟了 100 美元而極度不快。
- 蒙格家溫順的狗，唯一會咬人的時候，是在牠吃東西時把食物拿走。
- **賭徒**輸錢後急著扳平；**吃角子老虎**刻意設計大量「差一點就贏」的結果。
- **公開拍賣**：社會認同讓競標者相信別人的出價是合理的，被剝奪反應再推著他出更高價。
- **蒙格自己的教訓**：他以每股 115 美元買了 300 股貝爾里奇石油，第二天婉拒了再買 1500 股的機會（需要約 17.3 萬美元，得賣掉其他資產或借錢）。不到兩年，殼牌以約每股 3700 美元收購了這家公司——他因此少賺了 **540 萬美元**。

**對策**：
- 公開拍賣：巴菲特的做法——**別去**。
- 為了避免「用好資產去救已經變壞的投資」：蒙格建議趁年輕學會打撲克——學會**認賠出場**。
- 對抗意識形態造成的團體思維：刻意引進能力強、能言善辯的懷疑者。

**在工程團隊裡的樣子**：
- **拿掉功能比不加功能難得多**：已經給使用者的功能，就算很少人用，移除時也會引起強烈反彈。所以**加功能前要更謹慎**。
- **廢棄 API** 時，使用者的抗拒遠大於當初對新 API 的熱情——所以要給足夠的過渡期。
- **重寫系統**：已經投入的人月讓團隊不斷加碼（這也是 [[追求一致與逃避不適#避免不一致傾向|避免不一致]]）。對策是定期問：「如果今天從零開始，我們還會選這條路嗎？」

## ⚠️ 注意 / 什麼時候不適用

- **不要矯枉過正成自我貶低**：蒙格說有根據的驕傲（尤其是因為「可信賴」而驕傲）是建設性的力量。目標是**客觀**，而不是低估自己。
- **被剝奪反應也保護了有價值的東西**：人會努力守護重要的關係與承諾，這一部分正是這個傾向的功勞。
