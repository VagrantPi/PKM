## 🎯 什麼情境該想到我

當你**需要別人改變行為**——指出錯誤、糾正做法、交辦一件對方不太想做的事——又不想傷害關係的時候。這是全書最直接適用於**帶人與 code review** 的一章。

## ⚙️ 怎麼用（逐項）

### 先讚美再指出

*Begin with Praise*　**什麼時候會冒出來**：要退回一份不合格的稿件或報告／檢討會上要點出對方做得不夠的地方／開場第一句就要講缺點會很難聽／對方這次有好有壞而你只想講壞的

**書中的說法**：「用称赞和真诚的欣赏作开始。」

**機制**：「当我们听到别人对我们的称赞后，如果再听到其他不愉快的话，就比较容易接受了。」書中的比喻：「理发师替人修面时，先敷上一层肥皂水。」

**書中的案例**：
- **柯立芝總統**：先稱讚女秘書的衣服漂亮，接著說「從現在起，我希望你對公文的標點稍微注意一點」。（書中也評論這個做法「稍嫌明顯了些」。）
- **麥金利的講稿**：一位黨員寫的競選講稿不合用。麥金利先稱讚它「精彩絕倫」，再說要從黨的整體立場考慮，請他照幾個重點重寫。這位黨員後來成為他最得力的助選員。（原譯本把年份誤寫為 1856，麥金利競選總統是 1896 年。）
- **林肯給胡克將軍的信**：林肯先肯定他睿智善戰、有自信，再指出他阻撓前任將軍、散布需要獨裁者的言論。

**書中的但書**：規則寫的是「**真诚的**欣赏」。

**在工程團隊裡的樣子**：
- **Code review**：先指出真正做得好的地方（「測試案例涵蓋了邊界條件，很完整」），再提出問題。
- **注意「三明治回饋」的陷阱**：如果每次讚美後面都跟著「但是」，對方會學到「被讚美 = 壞消息要來了」，讚美就失去作用。書中柯立芝的例子被評為「稍嫌明顯」，正是這個問題。讚美要**真誠且具體**，不要只是負面意見前的鋪墊（見 [[待人處世的三個基本技巧#給予真誠的讚賞|給予真誠的讚賞]]）。

### 間接指出錯誤

*Call Attention to Mistakes Indirectly*　**什麼時候會冒出來**：對方自尊心強一講就炸／在有其他人的場合發現他的問題／想避開正面衝突地讓他知道／稱讚後面又接了一個但是

**書中的說法**：「间接地指出人们的过错。」

**機制**：「对人正面的批评，那会毁损了他的自重感，剥夺了他的自尊。」而「如果你旁敲侧击，对方知道你用心良苦，他不但接受，而且还会感激你。」

**書中的案例**：
- **司華伯與抽菸的工人**：工人在「禁止吸菸」的牌子下抽菸。司華伯沒有指責，而是遞給每人一支雪茄：「如果你们能到外面吸烟，我就更高兴了。」
- **百貨公司老闆**：看到店員聚在角落聊天、沒人招呼顧客。他一聲不響地自己去招呼顧客，然後把商品交給店員包裝。
- **牧師的妻子**：丈夫的講道稿寫得像百科全書。妻子說這篇稿子投給一本學術期刊會是好文章。丈夫聽懂了暗示，撕掉講稿，直接上台講道。

**在工程團隊裡的樣子**：
- **示範取代批評**：看到團隊的 commit message 都很草率，自己開始寫清楚的 commit message，並在 review 時稱讚寫得好的。百貨公司老闆的做法。
- **用自動化取代口頭提醒**：格式問題交給 `gofmt` 和 linter，就不需要有人去說「你的格式不對」。
- **注意邊界**：間接暗示對**明顯的問題**不適用。安全漏洞、會造成事故的 bug，要直接、清楚地指出——暗示太隱晦，對方可能根本沒聽懂。

### 先說自己的錯

*Talk About Your Own Mistakes First*　**什麼時候會冒出來**：要糾正晚輩或新人卻怕他反彈／開口前意識到自己當年犯過更糟的錯／指正的話說出口會顯得高高在上／想把上對下的指正變成同一陣線

**書中的說法**：「在批评对方之前，不妨先谈谈你自己的错误。」

**機制**：「如果批评的人先谦虚地承认自己也不是十全十美的、无可指责的，然后再指出人们的错误，这样就比较容易让人接受了。」

**書中的案例**：
- **卡內基的侄女**：19 歲的侄女來當他的秘書。卡內基提醒自己 19 歲時也很笨拙，之後糾正她時都先說：「你并不比我所犯的错误更糟……你比我在你现在年纪的时候要强多。」
- **布洛親王與德皇**：德皇威廉二世在報紙上失言，要首相布洛替他承擔責任。布洛一句「恐怕沒有人會相信是我建議陛下說那些話」激怒了德皇。他立刻補救：說自己在自然科學上遠不如陛下，只懂一點歷史與外交。德皇轉怒為喜。

書中對布洛的評語是：他「开始应该谈自己的短处，而指出德皇的长处」，卻先犯了錯——這個案例其實是**先示範錯誤、再示範補救**。

**在工程團隊裡的樣子**：
- **指導新人**：「我剛開始也常忘記處理這個錯誤，後來吃過一次虧……」比「你忘了處理錯誤」更容易被接受，而且順便傳遞了**為什麼重要**。
- **事故檢討**：資深成員主動分享自己過去造成的事故，能降低新人承認錯誤的心理門檻。

### 用提問代替命令

*Ask Questions Instead of Giving Orders*　**什麼時候會冒出來**：要交辦一件事給部屬時／準備直接下指令說你去做這個／對方一被命令就渾身不對勁／想把命令改寫成你覺得這樣如何

**書中的說法**：這個版本譯為「发问时，别用直接的命令」，譯句不太通順，意思就是**用提問代替直接命令**。

**書中的案例**（這一條全書只有這一個例子）：傳記作家訪問歐文·楊的同事，同事說三年來沒聽過他下過一道直接的命令。他總是說：「你不妨可以考虑一下」「你认为那个有效吗？」「你以为如何？」或者「或许我们这样措辞，会比较好一点。」他也讓助理自己做事，從錯誤中學習。

**機制**：「他保护了对方的自尊，而且使那人有了自重感……很容易取得对方的真诚合作，而对方不会有任何的反抗。」

**在工程團隊裡的樣子**：
- **Code review 的措辭**：
  - 命令：「把這個改成用 map。」
  - 提問：「這裡用 map 會不會比較快？這個 slice 可能會有幾千個元素。」
  - 提問版本多了**理由**，而且如果作者有你不知道的考量（例如「這裡最多只有 5 個元素」），他可以直接說明——你也可能學到東西。
- **注意**：提問必須是**真的問題**。如果你已經決定了、沒有討論空間，用提問包裝反而讓人困惑（「你覺得要不要修這個安全漏洞？」）。緊急或沒有選擇的事情，清楚直接地說。

### 顧全對方的面子

*Let the Other Person Save Face*　**什麼時候會冒出來**：要當著大家的面否決某人的提議／必須調整或撤換某人的職務／要拒絕一份對方認真準備的東西／事情已成定局但對方需要台階下

**書中的說法**：「顾全对方的面子。」

**機制**：「我们只需要花几分钟的时间想一想，再说一两句体恤的话，谅解到对方的观点，就可以解除很多刺痛。」

**書中的案例**：
- **奇異公司的斯坦梅茨**：他是電學天才，但不適合當會計部門的主管。公司給他「顧問工程師」的新頭銜，另外派人接主管職，他很高興。
- **會計師辭退季節性員工**：以前他辭退人時說得很草率。後來他先看過每個人這一季的表現，逐一稱讚他們的工作。被辭退的人不再覺得委屈，下一季被請回來時對公司更有好感。
- **凱末爾接受希臘將軍投降**：他握著對方的手說「兩位請坐，你們一定累了！」，又說「戰爭就像一場競技比賽，有時候高手也會遭遇失敗」。

**在工程團隊裡的樣子**：
- **私下指出，公開稱讚**：個人的錯誤在一對一時討論，不要在全員會議或公開頻道中點名。
- **調整職責時**：斯坦梅茨的例子在技術團隊中很常見——一位優秀的工程師被升為主管後表現不好。讓他回到資深技術職位時，要讓這個轉變是**正向的**（例如成為技術負責人），而不是降職。
- **事故檢討**：[[工具-無指責事後檢討]] 就是制度化的「顧全面子」——描述系統的缺陷，而不是某個人的錯。

### 稱讚每個微小進步

*Praise Every Improvement*　**什麼時候會冒出來**：帶新人而他還做得零零落落／小孩或學生剛學會一點點東西／對方有進步但離標準還很遠／你只在事情做到完美時才開口

**書中的說法**：「称赞最细微的进步，而且称赞每一个进步。」

**機制**：人有很多潛能沒有發揮出來，稱讚能讓他們知道自己的潛力。書中引用威廉·詹姆士的話：「若与我们应当成就的事业相比，我们不过是半醒着。」

**書中的案例**：
- **馴狗師**：狗的動作稍有進步，他就拍拍牠、稱讚牠、餵牠吃肉。卡內基問：為什麼我們對人不用同樣的方法？「为什么不用称赞来替代责备呢？」
- **卡羅素**：老師說他嗓子很壞，母親卻抱著他稱讚他在進步，自己赤腳工作省錢付他的學費。他後來成為著名的男高音。
- **狄更斯**：他在滿是老鼠的倉庫裡貼標籤，第一篇稿子被刊出時雖然沒有稿費，但編輯的讚許改變了他的一生。

**在工程團隊裡的樣子**：
- **帶新人**：第一個被合併的 PR、第一次獨立處理的事故，都值得明確地肯定。
- **稱讚要具體**：「你這次的 PR 描述寫得很清楚，review 起來快很多」——具體的稱讚告訴對方**什麼行為**值得繼續。
- **這和 [[工具-紅綠重構循環]] 的精神相同**：小步前進、每一步都有正面回饋，比等到大功告成才有回饋更能維持動力。

### 給對方一個好名聲

*Give a Fine Reputation to Live Up To*　**什麼時候會冒出來**：想讓某人改掉一個長期的壞習慣／要把重要的事託付給表現普通的人／想用一句你一向很負責來帶動他／念過很多次行為還是沒改

**書中的說法**：「给人一个美名让他去保全。」

**機制**：「如果你想改善一个人某方面的缺点，你要表示出他已经具有这方面的优点了……给他一个美好的名誉去表现，他会尽其所能，也不愿意使你感到失望的。」書中引用莎士比亞：「如果你没有某种美德，就假定你有。」

**書中的案例**：
- **女傭**：前雇主說她不會整理房間。新雇主卻對她說：「我可以打赌，你收拾房间，一定同你的人一样整洁干净。」她為了不辜負這個印象，把屋子收拾得乾乾淨淨。
- **典獄長的做法**：對付騙子，要「待他如同一位诚实、体面的绅士一样」。

**這條背後的機制**，可以用蒙格的 [[追求一致與逃避不適#避免不一致傾向|避免不一致傾向]] 解釋：人會努力讓自己的行為和別人（以及自己）對他的看法保持一致。

**書中的張力**：這一條書中並沒有堅持讚美必須屬實——有一個例子明說「即使并不真实」，士兵們聽到將軍的讚美後仍會努力達到那個水準。這和全書「必須真誠」的但書有衝突，書中沒有處理。實務上比較穩妥的做法是：**選一個對方確實有、但還沒充分發揮的特質**來強化，而不是憑空捏造。

**在工程團隊裡的樣子**：
- 「你對細節一向很仔細，這次的遷移計畫想請你來把關」——對方會更努力符合這個描述。
- 在團隊中公開說明某人的專長（「資料庫的問題可以問她」），能讓他更投入那個領域。

### 讓錯誤看似容易改

*Make the Fault Seem Easy to Correct*　**什麼時候會冒出來**：對方說我大概學不會這個了／任務看起來太難讓人不想開始／指出問題後對方整個洩了氣／想讓對方相信這件事其實不難

**書中的說法**：「用鼓励，使你要改正的错误，看来很容易做到；使你要对方所做的事，好像很容易做到。」

**機制**：說對方愚蠢、沒有天分，「你就破坏了他想要进取、上进的心情」。反過來，「多给一些鼓励，把事情看成很容易，使对方知道你对他有信心……那他就会付出最大的努力」。

**書中的案例**：
- **40 歲學跳舞**：第一位老師說他全都錯了、要從頭學，他就放棄了。第二位老師說他的基本步子是對的，還稱讚他「有一种很自然的韵律感」，他就願意繼續學下去。（當事人自己也承認，第二位老師「说的也许不是实在话」——這和真誠原則同樣有張力。）
- **教卡內基打橋牌**：朋友說「玩桥牌时，只要用点记忆和判断就行了……你曾写过一章关于记忆方面的文章」。卡內基因此第一次坐上牌桌。

**在工程團隊裡的樣子**：
- **把大的改進切成小步**：「把整個模組重構」讓人卻步；「先把這一個函式抽出來」看起來很容易。這不只是心理技巧，也是真正降低風險的做法（見 [[工具-小步重構]]）。
- **Review 意見要區分輕重**：把「必須修」和「可以考慮」分開標示，對方才不會覺得整個 PR 都錯了。
- **不要淡化真正嚴重的問題**：「讓錯誤看似容易改」是指修正的**路徑**要清楚、可行，不是假裝問題不嚴重。

### 使對方樂意去做

*Make the Other Person Happy to Do It*　**什麼時候會冒出來**：要把沒人想接的雜事分派出去／希望對方不是勉強而是心甘情願配合／一個改變需要對方長期配合下去／講不出這件事做完對他留下什麼

**書中的說法**：「使人们乐意去做你所建议的事。」（這個版本的章首總表漏列了這一條，但正文中有。）

**機制**：給頭銜、名義或權限，能讓人產生自重感。書中的說法是「这就是人类的天性」。

**書中的案例**：
- **豪斯上校與國務卿**：國務卿想當和平特使，但總統派了豪斯。豪斯告訴國務卿，以他的身分親自出面會引起太大注意、並不適宜——言下之意是他的職位太重要了。國務卿因此感到滿意。
- **威爾遜邀麥卡杜入閣**：威爾遜讓麥卡杜覺得，接受財政部長一職就像幫了總統一個大忙。**反例**：威爾遜冷落共和黨，沒帶他們去巴黎和會，使國際聯盟成了「他個人的主意」，最後美國始終沒有加入國聯。
- **抱怨的技師**：一位技師抱怨工作太多。老闆沒有減少他的工時，而是給他一間掛著「服務部主任」名牌的辦公室，他就不再抱怨了。

書中引拿破崙的話：「是的，有时人就是受玩具所统治。」書中自己也問：「是不是太幼稚了？或许是的。」

**在工程團隊裡的樣子**：
- **交辦任務時說明它的重要性與對方的角色**：「這次的資料庫升級影響所有服務，需要一個熟悉系統全貌的人來主導」——前提是這是事實。
- **給予真正的權限，而不只是頭銜**：讓負責的人有決定權。只給頭銜不給權限，就是技師的例子——短期有效，長期會被看穿。
- **威爾遜的反例很重要**：重大決策如果只是一個人的主意，其他人不會支持它。讓相關的人參與決策（也見 [[讓對方自己想通的六種方法#讓對方以為是他的主意|讓對方以為是他的主意]]）。
