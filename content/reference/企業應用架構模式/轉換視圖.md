## 🎯 什麼情境該想到我
當你「想用一支轉換程式，把領域資料逐項轉成 HTML 輸出」的時候。

## ⚙️ 怎麼用（步驟 / 公式）
意圖：以「轉換」為核心——寫程式逐項讀取領域資料，逐一產生對應的 HTML 元素。

做法要點：
- 為每種資料元素定義如何轉成輸出片段，逐項轉換組成整頁。
- 思維是「輸入 → 轉換 → 輸出」，而非在版型上挖洞填值。
- XSLT 是典型代表（把 XML 轉成 HTML）。
- 轉換邏輯是純程式，較易做單元測試。

## ⚠️ 注意 / 什麼時候不適用
- 版型不像樣板視圖那樣一眼可見，設計人員較難直接參與。
- 複雜版面用轉換描述可能冗長難讀（尤其 XSLT）。
- 需要接近成品的可視版型時，樣板視圖較直覺。
