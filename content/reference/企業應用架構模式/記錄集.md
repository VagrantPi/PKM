## 🎯 什麼情境該想到我
當你「想把資料表查詢結果，當成記憶體中的表格資料直接使用」的時候。

## ⚙️ 怎麼用（步驟 / 公式）
意圖：把查詢結果表示成記憶體中的表格資料結構，供 UI 與模組直接使用。

做法要點：
- 用列（row）與欄（column）組成的記憶體表格，鏡射資料庫的表格結構（如 .NET 的 DataSet）。
- UI 元件與商業模組可直接綁定、讀寫這份記錄集，開發直觀。
- 常見於「資料匯流排」風格：讓表格資料在各層之間流動、被繫結。

## ⚠️ 注意 / 什麼時候不適用
- 以表格為中心，較偏離物件導向的領域模型；領域邏輯複雜時未必合適。
- 環境沒有內建記錄集型別時，自造成本高。
- 讓 UI 直接依賴資料庫結構，schema 變動的影響會擴散。
