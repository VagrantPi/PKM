## 🎯 什麼情境該想到我

當你**被批評、被指責**，第一反應是辯解、反擊或冷處理的時候。

> 出處：阿德勒、普羅克特《溝通的藝術》（站內為簡體譯本，引文保留原書字形）。對應第十章 10.4 節「對批評以不防衛回應」。

## ⚙️ 怎麼用

### 為什麼會防衛

原書說，防衛是「我们保护自我表象、顾全自己面子的一个过程」；而且批評「命中要害」時，防衛最強。

### 兩大類做法

原書提供「兩種溝通的技巧」：先**尋找更多資訊**；當資訊還不夠時，再進到**同意批評者的看法**。

**A. 尋找更多資訊**——理由是「对方的话中常常包含了少许甚至许多的事实」，而且「当你愿意花点注意力在别人的批评上时，你不会失去任何东西」。

| 做法 | 原書的例子 |
|---|---|
| **1. 詢問詳情** | 面對「你不公平」「你從來不伸手幫忙」這種抽象攻擊：「我在什麼地方不公平了？」「我哪些時候不幫你了？」 |
| **2. 推測詳情** | 「當你說我沒有盡到我在這房子裡的那份責任的時候，你是指我對清潔打掃的幫忙不夠嗎？」 |
| **3. 對說話者的想法予以釋義** | 見下方店老闆的例子 |
| **4. 詢問批評者要的是什麼** | 「你的意思是希望我取消這個派對囉？」「不，我只是希望你在計劃之前先過問我的意見。」 |
| **5. 詢問行為的後果** | 丈夫以為妻子在意他賭輸的錢，妻子說：「這不是錢的問題，而是當你輸的時候你的心情總會低落個兩三天。」 |
| **6. 詢問還有哪裡出錯** | 目的是找出**真正的不滿**——對方被追問後才說出真正在意的事：「你是不是對我感到厭倦？」 |

**B. 同意批評者的看法**——原書說「你几乎可以在任何状况中都使用它们」：

| 做法 | 原書的例子 |
|---|---|
| **同意事實** | 「你是對的，我很生氣。」「現在你說得沒錯，我嘲笑了你。」 |
| **同意批評者的觀感** | 「我可以了解為什麼你會這麼想。我知道很多人都藉由說謊來獲得別人的讚同。」 |
| **解釋而不道歉** | 「我知道我遲到了。這是因為城裡出了個車禍……」 |

關鍵的區分：**同意事實不等於接受指責**；「同意那些批评，并不意味着迫使你要向他们道歉」。同意觀感也「並非去認同批評者的結論」。原書提到，研究者認為同意事實「对恢复批评中被损害的声誉有很大的效果」。

### 原書的完整示範：店老闆與顧客

- 顧客：「你管理的方法真差！……我以後再也不會來這裡消費了！」
- 老闆：「你看起來似乎心情很不好，告訴我你的問題，好嗎？」
- 老闆：「所以你在找你要的東西時得不到足夠的幫助，對嗎？」
- 老闆：「所以你的意思是，店員忽略了客人？」
- 老闆：「你不滿意的地方就是我沒有足夠的人手來迅速為你服務。」
- **結果**：顧客改口「我現在對於服務沒有抱怨了」；老闆也發現某些時段確實人手不足，這是業務上的疏失。

原書說釋義有兩個好處：批評者覺得有人在聽，態度會軟化；而且批評常常出自需求沒被滿足，釋義讓對方覺得被關注。

### 在工作中的樣子

使用者在 issue 上寫「這個 API 設計得爛透了」：
1. 詢問詳情：「可以說說是哪個部分讓你卡住嗎？」
2. 推測詳情：「是分頁的參數跟其他端點不一致嗎？」
3. 釋義：「所以你是花了很多時間才發現 `page` 是從 0 開始，而其他端點是從 1 開始？」
4. 同意事實：「你說得對，這兩個端點的慣例不一致。」——不需要道歉，也不需要同意「爛透了」這個結論。

## ⚠️ 注意 / 什麼時候不適用

- **語氣要真誠**：「倘若你在其他的心态下去询问详情，恐怕会引发更多的麻烦。」同一句「你希望我回答些什麼」，可以是真心，也可以是敵意。
- **推測要善意**：推測詳情時，猜測「必须是充满善意的」。
- **不保證能讓批評停止**：積極傾聽「不一定总是会减缓那些批评你的声音」。
- **先聽懂再同意觀感**：同意之前要先仔細聽、先發問。
- **真誠的道歉仍然是健康的**：原書說「有诚意的道歉是十分健康的」——這個工具不是用來取代該有的道歉。
- **關於離開**：原書在介紹防衛反應類型時提到，「在被对方连续攻击或辱骂批评的时候，'身体的躲避'就很合理」；但面對重要的人或「切中重點的批評」時，躲避會讓事情更糟。
