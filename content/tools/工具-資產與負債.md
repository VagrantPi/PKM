## 🎯 什麼情境該想到我

當你要**做一個大筆的財務決定**——買房、買車、升級設備——想判斷這筆錢是在累積財富還是在消耗財富的時候。

> 出處：羅伯特・清崎《富爸爸窮爸爸》（站內為簡體譯本，引文保留原書字形；原書的現金流圖在文字檔中缺失，以下依正文描述還原）。對應第二課。

## ⚙️ 怎麼用

### 唯一的規則

「你必须明白资产和负债的区别，并且尽可能地购买资产。……这就是第一号规则，也是仅有的一条规则。」

- 「资产就是能把钱放进你口袋里的东西。」
- 「负债是把钱从你口袋里取走的东西。」
- 「定义资产的不该用词语而是数字。」

作者也承認：「大多数会计师和财务专业人员不会同意这种定义法。」——這是一個刻意簡化、以現金流為準的定義。

### 三種現金流模式

| | 現金怎麼流 |
|---|---|
| **窮人** | 薪水 → 支出 |
| **中產階級** | 薪水 → 負債（房貸、車貸、信用卡）→ 支出；薪水增加時，「支出倾向也随着收入的增加而同等增加」 |
| **富人** | 資產產生收入 → 支付支出；剩下的再投入資產，形成良性循環 |

原書的結論：「富人买入资产；穷人只有支出；中产阶级买他们以为是资产的负债。」

### 財富的定義：能活多久

原書借用巴克敏斯特・富勒的定義：「财富就是支持一个人生存多长时间的能力，或者说如果我今天停止工作，我还能活多久？」

**可以自己算**：資產每月產生 1,000 美元，每月支出 2,000 美元 → 「只能活半個月」。資產每月產生 2,000 美元，等於支出 → 就算辭職也能生存。

### 自住的房子為什麼是負債

原書列出的理由：
1. 每幾年換屋，又重新背 30 年的貸款。
2. 用稅後收入付房貸。
3. **財產稅**（作者岳父母每月 1,000 美元）。
4. 房價不一定漲（原書的例子：100 萬美元跌到 70 萬）。
5. **最大的損失是機會成本**——這筆錢本來可以去買會產生收入的資產。

作者也說：「我并不想让所有人都同意我的观点。」他們夫婦也喜歡大房子——只是知道那不是資產。

### 真正的資產清單（第三課）

不需要本人到場的事業、股票、債券、共同基金、會產生收入的房地產、票據、智慧財產權（音樂、手稿、專利），以及其他有價值、可能增值、流通性好的東西。

### 新婚夫婦的惡夢

收入增加 → 買房 → 財產稅、新車、新家具 → 信用卡 → 用房屋抵押的貸款還信用卡，把負債分散到 30 年 → 又刷卡購物。「如果你发现你已在洞里，那就别再挖了。」

### 在工程師身上的樣子

| 看起來像資產 | 實際上 |
|---|---|
| 最新款的筆電 | 負債（除非它直接幫你賺錢——例如接案用的工具） |
| 車子 | 負債——原書說新車開出停車場就損失 25% |
| 自己寫的付費 App | 資產（每月帶來收入） |
| 指數型基金 | 資產 |

## ⚠️ 注意 / 什麼時候不適用

- **定義是刻意簡化的**：專業會計不會同意；而且原書的資產清單裡也包括「可能增值、流通性好」但不一定有現金流的東西——原書本身在這點上並不完全一致。
- **帳面淨值不準確**：資產賣掉時只能拿回一部分，還要繳稅。
- **錢治不好財務無知**：「钱只是使你头脑中的现金流向图的流向更加明显……增加了收入的同时也增加了支出。」
