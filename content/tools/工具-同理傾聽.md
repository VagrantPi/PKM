## 🎯 什麼情境該想到我

當別人**帶著情緒來找你**——抱怨、生氣、沮喪——而你的第一反應是給建議、安慰或解釋的時候。

> 出處：馬歇爾・盧森堡《非暴力溝通》（站內為簡體譯本，引文保留原書字形）。

## ⚙️ 怎麼用

### 定義（原書第七章「用全身心傾聽」）

「为了倾听他人，我们需要先放下已有的想法和判断，全神贯注地体会对方。」原書引一句佛教格言：「不要急着做什么，站在那里。」

聽的內容：「不论别人说什么，我们只听到他们此时此刻的（a）观察，（b）感受，（c）需要，和（d）请求。」

### 妨礙傾聽的十種反應

原書列出作者朋友霍利・漢弗里整理的清單——這些都是**好意但會阻斷傾聽**的反應：

| 反應 | 例子 |
|---|---|
| 建議 | 「我想你應該……」 |
| 比較 | 「這算不了什麼。你聽聽我的經歷……」 |
| 說教 | 「如果你這樣做，你將會得到很大的好處。」 |
| 安慰 | 「這不是你的錯，你已經盡最大努力了。」 |
| 回憶 | 「這讓我想起……」 |
| 否定 | 「高興一點。不要這麼難過。」 |
| 同情 | 「哦，你這可憐的人……」 |
| 詢問 | 「這種情況是什麼時候開始的？」 |
| 辯解 | 「我原想早點打電話給你，但昨晚……」 |
| 糾正 | 「事情的經過不是那樣的。」 |

### 怎麼給反饋：用疑問句猜

原書建議用**疑問句**，語氣是在猜，不是在宣布：

- 觀察：「上週我有三個晚上不在家，你說的是這回事？」
- 感受與需要：「你很灰心？你希望得到肯定，是嗎？」
- 請求：「你是不是想請我幫你預訂酒店？」

原書也列了**反例**——不用心體會、直接丟問題給對方的問法：「你現在心情怎麼樣？」「你希望我怎麼做？」

### 什麼時候對方已經說完了

原書的判斷依據：對方「就会变得轻松」，或者更明顯地，「他停止了谈话」。拿不準時可以問：「你還有什麼話要告訴我嗎？」

**不要太早問對方的請求**，要先讓對方充分表達，否則會「被看作是应付」。

### 原書的案例

- **「你從不好好聽我講話」**：先生回「我怎麼沒有？」，太太回「你就是沒有！」作者代替先生回應：「聽起來，你很失望。你需要體貼，是嗎？」太太聽了流淚，先生很驚訝：「她想要的只是這個？」
- **醫院裡的老太太**：她一直說「我不想活了」，護士們一直安慰、給建議都沒用。一位義工問她：「你的意思是你不願意活下去了？」老太太放鬆下來，當天就開始吃飯、吃藥——她「需要有人能理解她深深的絕望」。
- **女兒說「我醜得像一隻豬」**：作者回「你是世界上最美麗的女孩！」，女兒摔門出去。作者事後認為比較好的回應是：「你對你今天的形象感到很失望嗎？」——安慰與否定都在十種反應裡。

### 原書引用的證據

- 「关于劳资谈判的研究显示，如果双方同意在作出答复前先准确地重述对方的观点，那么，达成协议的时间将可以比平时缩短一半。」
- 作者在研討班的非正式測驗：23 位心理醫生對「我快要崩潰了，我找不到活下去的理由」的書面回答中，**只有 3 個**讓人覺得被理解。

### 為什麼有效

- 反饋讓對方確認你是否聽懂、讓他糾正你的誤解、也讓他更了解自己。
- 急著分析就是在診斷人：「我们是在诊断人——我们并没有倾听他们。」
- 被傾聽的人才會轉過來聽你：「一旦我们用心倾听他们……他们一般也就会开始留意我们的感受和需要。」

### 在工作中的樣子

同事說「這個需求又改了，我已經重寫第三次了」：
- ✗ 建議：「你應該要求 PM 先把規格寫清楚。」
- ✗ 比較：「我上次改了五次。」
- ✓ 「改到第三次，聽起來你很挫折——你希望做出來的東西不會白費，是嗎？」

## ⚠️ 注意 / 什麼時候不適用

- **反饋不一定要說出口**：原書提到一位先生從來沒有把父親的感受說出來，只在心裡體會，父子關係就變得親密；作者自己也「有时说出我的理解，有时则没有」。重點是**體會**，不是套句型。
- **語氣要像在猜**：「如果我们的语气很肯定，仿佛是在宣布他们的内心世界，那么，通常不会有好的反应。」
- **被說「不要用溝通技巧套我的話」時**：繼續傾聽他。如果常被懷疑誠意，檢查自己是不是在機械地使用。
- **對生氣的人不要說「不過」「可是」「但是」**。
- **自己也痛苦到無法傾聽時**，原書給三個選項：體會自己的感受和需要；大聲提出請求；換一個環境。
