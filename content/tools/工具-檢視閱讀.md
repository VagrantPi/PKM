## 🎯 什麼情境該想到我

當你**拿到一本書或一份長文件，想在有限的時間內判斷值不值得讀、它在講什麼**的時候。

> 出處：艾德勒、范多倫《如何閱讀一本書》（站內為郝明義、朱衣的中譯本，引文保留原書字形）。對應第四章。

## ⚙️ 怎麼用

### 兩種檢視閱讀

原書說初學者要分開練習，有經驗的人會同時進行。

### A. 有系統的略讀（目的：判斷值不值得細讀）

1. **看書名頁與序**：特別注意副標題、宗旨、作者的特殊角度，在腦中把書歸類。
2. **研究目錄**：「就像是在出发旅行之前，要先看一下地图。」
3. **檢閱索引**：評估涵蓋的議題範圍、提到的書與作者；重要的詞條至少看一下引用的那幾頁。
4. **讀出版者的介紹**（書衣文案）：這常是作者在出版社協助下親自寫的主旨；如果文案只是在吹捧，也能看出這本書沒什麼重點。

→ **做完這四步是一個決策點**：要不要讀這本書？要讀的話，才開始「真正地略讀」：

5. **挑幾個看來跟主題息息相關的篇章**；開頭或結尾有摘要就仔細讀。
6. **東翻西翻**，念一兩段，有時連讀幾頁但不要太多，隨時找主要論點的訊號。「最重要的是，不要忽略最后的两三页。」

整個過程花「几分钟，最多不过一小时」。原書說略讀像「打穀」，把穀粒從糠殼中篩出來。

### B. 粗淺的閱讀（面對難讀的書）

「头一次面对一本难读的书的时候，从头到尾先读完一遍，碰到不懂的地方不要停下来查询或思索。」只注意看得懂的部分——「就算只有 50％或更少」也有幫助。原書在摘要中稱這是「最最重要的一个规则」。

**原書的例子**：
- **高中生讀莎士比亞**：一幕一幕讀、一個生字一個生字查、一條註腳一條註腳讀，讀到最後忘了開頭——「从来没有真正读过莎士比亚的剧本」。應該先一次讀完。
- **《國富論》**：堅持每一頁都懂才往下讀，會錯過工資、地租、利潤、市場定價、壟斷之害、自由貿易這些大原則。

### 閱讀的速度

理想是能用不同速度閱讀：「慢不该慢到不值得，快不该快到有损于满足与理解。」原書也教了一個矯正「逗留與倒退」的方法：把大拇指、食指、中指併攏當指針，沿著文字移動，速度比眼睛覺得舒服的快一點——練習後可以快兩三倍。

原書對速讀的看法：速讀課程只處理基礎閱讀的層次；問題在理解力——「没有经过分析阅读，你就没法理解一本书」。

### 在工作中的樣子

**評估一個開源函式庫**（對應略讀的步驟）：
1. README 的第一段與副標題（書名頁）
2. 文件目錄或 API 列表（目錄）
3. 搜尋你關心的關鍵字，例如 `context`、`timeout`（索引）
4. 專案的定位說明（出版者介紹）
→ 決策點：值得深入嗎？
5. 看兩三個與你的用途最相關的範例
6. 看 CHANGELOG 的最近幾版、issue 列表的最後幾頁（最後兩三頁）

**讀一份很難的設計文件**：先從頭到尾讀一遍，不懂的地方做記號但不停下來；第二遍再處理那些記號。

## ⚠️ 注意 / 什麼時候不適用

- **這是非常主動的閱讀**：「这是一种非常主动的阅读」，不夠靈活、無法集中精神就做不到。
- **專注不等於理解**：理解要能回答更進一步的問題。
- **超快速讀是可疑的成就**：原書說，它常常只說明你在讀一本根本不值得讀的書。
- **就算是想仔細讀的書，也要先略讀**。
