## 🎯 什麼情境該想到我

當你**需要向伴侶、同事或主管提出不滿**，但擔心一開口就吵起來的時候。

> 出處：麥克・尼可斯《好好說話第一步》（*The Lost Art of Listening*，站內為簡體譯本，引文保留原書字形）。對應第十章〈如何抱怨卻不引發爭吵〉。

## ⚙️ 怎麼用

### 問題在哪裡

「如果对方觉得你是在攻击他，可能就会引发你不想见到的火爆场面。」對方抗拒的常常不是事情本身，而是背後的訊息：「你是老大」。

### 開口之前先判斷

- 這件事**對你有直接影響**嗎？
- 你和對方是什麼**關係**？
- 對方**可能改變**嗎？
- 已經說過無數次的事，就放手——「你的挑剔只会让别人学会"耳聋"而已」。

### 怎麼抱怨（原書列出的做法）

| 做法 | 原書的說法或例子 |
|---|---|
| **溫和地開始** | 「从温和地说出来开始。」 |
| **先預告** | 「我在煩一件事，我需要跟你談談。今晚下班後可以嗎？」事先通知讓對方有準備 |
| **注意時間與地點** | 兩人都冷靜、輕鬆、能獨處的時候 |
| **私下說** | 不要在朋友或孩子面前挑毛病，也不要批評對方的家人或朋友 |
| **用求助開場** | 「我碰到問題了」「我需要你幫忙」 |
| **避開四種句型** | 「你為什麼總是……」「你從來就不……」「你應該……」「你為什麼就不能像……」 |
| **談感受，不談缺點** | 「我希望我們出門時，你可以穿得正式一點。當你把最好的衣服穿上時，我覺得自己好特別！」優於「為什麼你總是這麼邋遢？」 |
| **只談行為，談喜惡不談對錯** | 說清楚這是「我喜歡／不喜歡」，而不是「你對／你錯」 |
| **給對方說話的機會** | 「即便你是那个抱怨的人，也要记得给对方说话的机会。」 |
| **先了解對方為什麼不想改變** | 見下方溫蒂與漢克的例子 |
| **越短越好** | 「带有情绪的讨论，应该越短越好。」 |

原書在相鄰的〈如果你被認為是一個嘮叨者〉還補充：「要求少，就會得到更多」；提出要求後加一句「你認為如何？」；先說「我知道這不是你的錯」；對方聽完後說「謝謝你聽我說」。

### 原書的案例：溫蒂與漢克

溫蒂請漢克幫忙載孩子，漢克答應了。溫蒂沒有就此打住，而是追問：「我知道你不想這麼做……你什麼時候最不想開車？」漢克很感謝她的體諒，說他討厭上班日晚上九點之後出門。溫蒂再問：「還有什麼嗎？」漢克坦白說，他覺得她載孩子去太多地方了。溫蒂回：「也許你是對的，也許我真的做得太多了。」

**讀法**：對方一口答應時，不代表問題解決了——原書說「对方没说什么就同意了，可见他是不可能做到的」。

### 反例：壓了三個月才說

蓋爾把三個月的不滿一次倒出來，話越說越快、越來越有壓迫感，里昂覺得被攻擊，最後甩門離開。第九章的提醒：「早点说出来，你就更容易降低声调。」「不要说："你从来没做什么事！"试着说："我的家务负担太重了，我需要你的帮忙。"」

### 為什麼有效

- 不說就會爆發，形成「控制—宣洩」的循環。
- 聽者是對情緒做反應的：生氣地說，傳達出去的就只剩你的氣憤。「焦虑是倾听的敌人！」

### 在工作中的樣子

向主管反映 on-call 負擔太重：
- ✗ 在團隊會議上說「為什麼總是我值班？」
- ✓ 私下約時間：「我有件事想跟你討論，這週找個時間可以嗎？」→「這個月我值了 9 個晚班，睡眠受影響，白天的工作也做不完（具體行為與影響）。我需要你幫忙想想輪班的方式。你覺得呢？」

## ⚠️ 注意 / 什麼時候不適用

- **不接受「不」，就無法信任「是」**：「如果你不愿意接受"不"的答案，那你就无法信任"是"的答案。」
- **想要事情完全照你的方式做**，原書的建議是：「那么最好自己动手。」伴侶和同事都希望被當成大人對待。
- **表達感受不等於宣洩情緒**；但作者也說：「我不是建议我们要保持情绪上的疏离。」
