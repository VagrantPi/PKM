## 🎯 什麼情境該想到我

當你需要**說出一個不滿或要求**，又不想讓對方覺得被審判、開始防衛的時候。

> 出處：阿德勒、普羅克特《溝通的藝術》（站內為簡體譯本，引文保留原書字形）。這張卡整合第五章「使用『我』和『你』的語言」與第十章「清晰訊息處方」。

## ⚙️ 怎麼用

### 「你」語言 vs「我」語言（第五章）

- **「你」語言**表達的是對他人下論斷，「会激起他人的戒心」，也意味著說話者自認有資格評斷別人。
- **「我」語言**代表「说话者愿意为不满负起责任」。

**「我」陳述的四個部分**（順序不固定）：
1. 他人的行為
2. 你的詮釋
3. 你的感受
4. 他人行為對你的後續影響

原書的例子：「你今天早上沒有準時來接我（行為），我因而上課遲到被教授嘮叨（後續影響）……這就是我為什麼那麼生氣的原因（感受）。」

**使用多少部分**：「当被误会或可能会引发别人强烈的防卫之心时」最好四部分齊全，其他情況用一兩部分就夠。

### 原書的前後對照：麗貝卡與湯姆

- **「你」語言**：「你去哪裡了？你應該在十二點半回來……」湯姆越來越防衛，最後說「我不會再要求你幫我忙了」。
- **「我」語言**：「湯姆，我需要和你討論一個問題。」→「嗯，我必須告訴你這會讓我很為難……我很擔憂這個情形。」湯姆回：「我會在處理我的私事時更留神。」

原書的評語：「即使汤姆没有改变，丽贝卡也可以把她心中的那块石头给放下。」

### 完整版：清晰訊息的五個部分（第十章）

| 部分 | 要點 | 原書的對照 |
|---|---|---|
| **行為** | 客觀描述，不帶解釋 | ✗「你是個吝嗇鬼」 ✓「我經常替你付咖啡和點心的費用，而你從來沒有替我付過，我覺得你是個吝嗇鬼」 |
| **解釋** | 承認解釋是主觀的，把推論過程說出來 | ✗「假如你關心我，你就應該更常寫信給我」 ✓「當我不能從你那邊收到信或卡片時，我想那是因為你不夠關心我」 |
| **感覺** | 分清真正的情緒與冒充的情緒 | 「我覺得很想要離去」其實是意圖；「我覺得你是錯的」其實是解釋 |
| **結果** | 三種：**說話者**身上發生了什麼、**接收者**身上發生了什麼、**其他人**身上發生了什麼 | 別人「经常无法」自己察覺他的行為造成的結果 |
| **意圖** | 三種：你所**秉持的觀點**、對他人的**訴求**、你未來**打算怎麼做**；多個意圖可能**互相衝突** | 「我曾問過三次，叫你償還我借你的 25 美元……除非我們現在弄清楚，你別期待我會再借你任何東西。」 |

**使用要點**：順序可以打亂（有時最好從感覺開始）；用詞要符合你的風格；兩個元素可以合在一句；必要時重複。

### 原書引用的研究

- 衝突研究顯示，**滿意的伴侶多提行為型的抱怨**（「你總是把襪子丟在地板上」），**不滿意的伴侶多提人格型的抱怨**（「你這個邋遢的傢伙」）。人格攻擊「即使冲突结束后也很难忘记」。
- 使用「我們」語言的夫妻，婚姻滿意度較高；「我」和「我們」合用（例如「我想我們……」），「被人接受的机会很高」。

### 在工作中的樣子

- ✗「你的 PR 總是拖到最後一刻才送。」（「你」語言 + 人格型）
- ✓「這個 sprint 的三個 PR 都在截止日前一天才送出（行為），我猜可能是任務被低估了（解釋），我有點焦慮（感覺），因為 review 時間不夠，上週就有一個 bug 沒被看到（結果）。我想下個 sprint 試試看每完成一個部分就先送一個小 PR，你覺得呢？（意圖）」

## ⚠️ 注意 / 什麼時候不適用

- **言行要一致**：「如果……你的声调、面部表情和姿势全部都在传达着使用'你'字的信息，那么别人也会对你产生防卫。」原書第六章也說，口語和非口語不一致時，人們「多仰赖非口语的部分」。
- **沒有人喜歡聽到自己造成了困擾**：原書引 Thomas Gordon 的話——「我」訊息再好，也不會讓對方愉快。
- **要有節制**：「我」訊息用太多會顯得自我中心；原書提到，有「溝通自戀」傾向的人經常只用「我」。
- **「我們」語言有時顯得冒昧**：對方可能回「也許是你有問題」。
- **陳述結果時不要加上道德說教**。
