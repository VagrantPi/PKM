## 🎯 什麼情境該想到我
當你想理解「錢的價值到底靠什麼撐著」「為什麼有人推崇黃金／比特幣」「國家為什麼能不斷印鈔」的時候。對應書中「魚本位的破滅」。

## ⚙️ 怎麼用（判斷一種貨幣的底氣）
1. **問：它有沒有內在價值？**
   - **硬通貨（如金銀、書中的真魚）**：稀少、耐久、質地均勻、人人想要，即使不當錢也有用途——價值來自本身。
   - **法定貨幣（fiat，紙幣）**：本身無內在價值，「因政府命令而具有價值」，價值完全由人的信心主觀決定；可無限發行。
2. **看錨定是否還在**：貨幣一旦能兌換硬資產（魚本位／金本位），就有紀律；一旦關閉兌換窗口、切斷錨定（如 1971 年美元脫離黃金），發行就再無上限。
3. **警覺「信心」的脆弱**：法幣靠信心維繫，信心一旦崩塌就可能變廢紙；歷史上政府走投無路狂印紙幣，多以國民慘賠收場。
4. **定位當下**：我們正處於「史上最大的貨幣實驗」——過去數十年沒有國家發行真實貨幣。理解這點，才能判斷持有現金、實體資產或硬通貨的取捨。

### ★ 1971 年發生了什麼

1971 年 8 月，美國宣布停止以固定價格將美元兌換成黃金（「關閉黃金窗口」），布列頓森林體系的固定匯率隨後瓦解。此後主要貨幣都成為**法定貨幣**：沒有任何實物資產作為錨定，發行量由央行決定。這是書中「魚本位破滅」所指的真實事件。

### ★ 硬通貨與法定貨幣的取捨（兩面都要看）

| | 硬通貨（金本位、書中的魚本位） | 法定貨幣 |
|---|---|---|
| 發行紀律 | 受限於黃金存量，政府很難任意擴張 | 由央行決定，可以快速擴張 |
| 購買力 | 長期較穩定 | 長期持續下降（見 [[工具-通貨膨脹的真相]] 的算式） |
| 應對危機 | 缺乏彈性：銀行擠兌或經濟衰退時無法增加貨幣供給 | 可以在危機時注入流動性 |
| 經濟學界的主流看法 | 多數經濟學家認為金本位加劇了 1930 年代大蕭條的通縮與傳播 | 目前全球主流制度，但依賴央行的紀律與獨立性 |

本書偏向左欄；主流經濟學偏向右欄。兩邊都承認的事實是：**法定貨幣的價值依賴對發行者的信任**，而歷史上確實有惡性通膨的案例（例如 1920 年代的德國威瑪共和、2000 年代的辛巴威）。

### ★ 為什麼有人推崇比特幣

比特幣的設計直接回應了這張卡的論點：**總量上限 2,100 萬枚、發行速度由程式碼決定**（約每 210,000 個區塊減半一次，見 [[工具-去中心化共識與PoW]]）。它試圖在數位世界重建「硬通貨」的稀缺性。但它的價格波動遠大於黃金與主要法幣，目前主要被當作投機或投資資產，而不是日常的計價單位。
