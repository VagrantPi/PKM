### Motion Library 動態收藏
`網站` · 網頁（Hannah，UI/UX Designer 整理） · 327 種（2026-10-29） · ⬜ 待試

**做什麼**：一本網頁動態效果的圖鑑。想在頁面上加動效、卻說不出要什麼樣子時，先在這裡挑，再把描述丟給 agent 照做。
- **三軸交叉篩選**：「元件」（文字 105、按鈕、卡片、背景、游標…）×「時機」（進場、退場、切換、循環待機、懸停點擊、捲動觸發、拖曳）×「情境」（標題 Hero、強調重點、數字資訊、轉場…），例如「按鈕 × 懸停」。另可依技術篩：CSS 194、GSAP 119、Canvas 14。
- **每格都有可試玩的預覽**，互動類可以直接用滑鼠移動、捲動、拖曳。
- **「複製 AI 提示詞」複製的是外觀與節奏的描述，不是程式碼**。例如閃電砸落：「先閃兩下強光並出現一道閃電線，文字從 2 倍大瞬間砸下縮回原尺寸，落地時輕微震動……整段約 2.4 秒」，最後一律加上「配色請依照網站既有的主題色」。

**怎麼用**：篩到想要的效果 → 複製提示詞 → 貼給 Claude Code 等 agent，並說明要套在哪個元件、用 CSS 還是 GSAP。描述裡的秒數、縮放倍率就是驗收時對照的規格。

**⚠️ 注意**
- **預覽是作者重製的示意**，名稱與描述來自 Threads 上其他人的整理。網站自述「僅供個人參考學習」，不要整段照抄到商用作品。
- **提示詞只描述外觀，沒有效能與無障礙要求**。實作時要自己補（我的建議）：尊重 `prefers-reduced-motion`、只動 `transform`／`opacity`，避免觸發重排。
- GSAP 類的效果是用 GSAP 3.13 示範的。
- 我還沒實際拿提示詞讓 agent 做過，產出品質未驗證。

### Mesh Avatar Studio
`本機應用` · Claude Code・Codex · MIT（範例角色 Miko 另有授權） · ★1.6k（2026-10-30） · ⬜ 待試

**做什麼**：給一張插畫，做出會眨眼、說話、轉頭、呼吸、頭髮會飄的 2D 網格虛擬形象（mesh avatar），可以用自己的臉和聲音即時驅動，接進 OBS 直播。分工是：**coding agent 負責綁骨架、切圖層、自我檢查**，**人在本機編輯器拖點微調**。它不是 skill，而是一個 repo：你在 repo 裡開 Claude Code 或 Codex，agent 照 `docs/agent-guide.md` 一步步做。

**核心**（agent guide 的設計值得看）
- **先驗模型的視力，不合格就停**：開工前先跑 `vision-check.py`，產生一張帶編號標記的圖，讓模型讀座標、打分數。分數不及格，就告訴使用者「這個模型讀到的座標很可能偏掉，後面大多要手修」。指南也要求 agent 先報自己是哪個模型，不在推薦清單上就先問要不要繼續。
- **座標一律在放大的網格上讀**：用 `grid.py` 畫格線，再逐區放大。「直接看整張圖估座標」被列為不可接受。
- **用固定姿勢的渲染圖自我審查**：`render-poses` 會輸出閉眼、張嘴、左右轉 ±30°、抬頭低頭、各種表情、頭髮擺動的截圖與接觸表，逐張檢查，例如閉眼不能露出虹膜、轉頭不能撕裂網格。**沒看圖就回報成功**也被列為不可接受。
- **素材不出本機**：插畫只放在 `projects/`，不 commit、不上傳。唯一例外是第 6 步，要畫閉眼、嘴型、表情的差分圖時，**經使用者同意才**把圖和遮罩送去產圖。

**裝與用**
```sh
# 需要 Node.js 22.17+ 與 Git
npx create-mesh-avatar-studio
cd mesh-avatar-studio
npm run dev          # 開編輯器，先看內附範例
```
- **讓 agent 做自己的角色**：在 repo 裡對 agent 說「Create an avatar from this image following docs/agent-guide.md: `/path/to/your-image.png`」。正面、露出頭肩、透明背景的 PNG 效果最好。
- **Codex 一鍵版**：`npm run create -- /path/to/image.png`。通常要花幾十分鐘。`--random` 可以讓 Codex 先畫一個新角色再做。
- **完整流程**要 Python 3.10＋uv 與 Playwright Chromium，`npm run doctor` 會列出缺什麼。
- **輸出**：可匯出單一 `.mavatar` 檔分享。Live 頁可以接攝影機與麥克風，複製 OBS Browser Source 網址。不想安裝的話，也有純瀏覽器的 Player。

**⚠️ 注意**
- **推薦模型**：Claude Code 用 Opus 5.5、Codex 用 GPT-6.1 Sol。指南說讀像素座標需要很強的視覺能力，換弱一點的模型品質會掉。
- **Claude Code 不能產圖**：閉眼、嘴型、表情的差分圖只有 Codex 能直接畫。Claude Code 只會幫你準備遮罩和提示詞，要自己拿去其他產圖工具。沒有差分圖時，眨眼和說話只靠網格變形，比較不自然。
- **Codex 一鍵版會把插畫和遮罩送到 OpenAI**，執行前會先問；加 `--no-variants` 就全部留在本機。另外它用 `--approve-for-me` 跑，agent 要在沙箱外執行工具（例如開 Chromium 截圖）時會**自動核准，不經過你**。
- **攝影機和麥克風的資料都留在本機**，傳到直播畫面的只有動作數值。
- **範例角色 Miko 不屬於 MIT 授權**，可以用在自己的作品裡修改，但不能單獨轉散佈。
- Rust 原生版本與 macOS 桌面角色還是實驗功能。

**🔗 相關**：→ [[工具-讓LLM產出可驗證的產物]]（同一個思路：先校準模型能力、用渲染結果檢查自己，不讓模型只靠「看起來對」就回報完成）

### PulsoIcon
`套件` · React 18+・Vue 3.5+・Svelte 5・Jetpack Compose・SwiftUI · ISC · ★206（2026-11-08） · ⬜ 待試

**做什麼**：一套**會動的圖示庫**，共 9,955 個圖示，**每個都有為它單獨寫的動畫**，不是同一種特效套在全部圖示上：鈴鐺會搖、行事曆的環會抬起、垃圾桶會掀蓋、時鐘指針會轉。平常就是一般的 24×24 圖示，滑鼠移到（或鍵盤 focus 到）它所在的按鈕、連結、分頁上才播放。網站 [pulsoicon.com](https://pulsoicon.com) 可以瀏覽、試玩、複製程式碼。

**核心**
- ⭐ **React 版可以直接換掉 lucide-react**：元件名稱（`Calendar`、`CalendarIcon`、`AlertCircle` 這類別名）和 props 都一樣，通常只要改 import。
- **圖示來源**：全部 2,020 個 Lucide 圖示（截至 Lucide 1.68），加上 Tabler Icons 與 Iconoir 的形狀，以及約 3,700 個自繪圖示；品牌 logo 共 3,042 個，以 `Brand` 開頭（`BrandGithub`、`BrandOpenai`）。
- **觸發範圍是「最近的可互動元素」**：hover 或 focus 到最近的 `button`、`a`、`label`、`summary` 或 `role="button|link|tab|menuitem"` 元素就播；其他元素加 `data-icon-trigger` 也能當觸發點（例如整張卡片）。
- **控制動畫的 props**：`animated={false}` 完全靜止；`autoAnimated={false}` 關掉 hover 觸發，但還能用 ref 或 `play` 從程式碼播放；`play` 是 true 就播、false 回到靜止。另有 `solid` 實心版，約 1,700 個圖示有正式的實心圖。
- **系統要求減少動態時就完全不動**（`prefers-reduced-motion`），也只打包你 import 的圖示：README 說三個圖示未壓縮約 12 kB（未驗證）。
- 五個平台共用 `packages/core` 的同一份資料，動畫與 props 都一致。

**裝**（照抄 README）
```bash
npm install pulsoicon-react    # Vue：pulsoicon-vue；Svelte：pulsoicon-svelte；其他框架：pulsoicon-core
```
```tsx
import { Bell, Trash2 } from "pulsoicon-react";
<button><Bell size={20} /> Notifications</button>
```
Android 用 `implementation("com.citypulso:pulsoicon-compose:<version>")`；iOS／macOS 用 Swift Package 加這個 repo。React 套件在 5.2.1 以前叫 `pulsoicon`，6.0.1 起改名 `pulsoicon-react`，舊專案要改 import。

**⚠️ 注意**
- **授權要附 LICENSE**：可以商用、可閉源，但只要打包出去（app、網站 bundle、模板、自己的套件），就要附上 PulsoIcon 的 LICENSE 檔，例如放在「第三方授權」頁。裡面已經包含 Lucide、Tabler、Iconoir、Hugeicons、Phosphor 的授權聲明。
- **品牌 logo 是各品牌的商標**，而且是為這套重畫的簡化線稿，不是官方 logo；使用時要遵守各品牌自己的規範。
- **圖示本身是 `aria-hidden`**，無障礙標籤要加在外層的按鈕或連結上。
- **專案很新**：★206、5 個 fork、30 個 commit，維護者是 CityPulso；長期是否持續維護還看不出來。

### PrettySites
`網站` · 瀏覽器（LLC Mahaon AI 經營） · 免費＋付費（2026-11-14） · ⬜ 待試

**做什麼**：一間「網站提示詞」商店。每個設計都是一個做好的網站樣式（作品集、SaaS、電商、3D 互動……依產業分類，首頁標示每天上新），附**完整提示詞、原始檔與媒體素材**。挑一個喜歡的，複製提示詞，貼進 Claude、Codex、Cursor、Lovable 這類 AI 建站工具，讓它照著做出來，再改成自己的內容。另有 Background Studio：輸入文字、選動態效果，複製出一個首屏設計。

**怎麼用**（官方 How it Works）
1. 挑設計、按複製或「Copy full prompt」。
2. 整段貼進 AI 工具送出，等它做完。
3. 一次只改一件事，例如換 logo、文字、圖片、顏色；需要時附上自己的檔案。
4. 自己檢查手機版、連結、表單，再從建站工具發布。PrettySites 不會幫你發布。

官方也給了現成的指示可以複製：「加到既有網站」時要 AI 保留原本的頁面與功能、替換內容前先問；成品跟預覽不一樣時，附上預覽截圖要它逐項比對修正。

**⚠️ 注意**
- **有付費內容**：分「免費」與「付費」設計，頁首寫「2 個付費設計 $9」，另有吃到飽的 Go Unlimited 會員；會員價格我沒抓到（定價頁 404）。
- 它賣的是**提示詞與素材**，最後的程式碼品質取決於你用的 AI 工具，預覽畫面不等於你一定做得出來。
- 我還沒實際試過，產出品質未驗證。

### Fontshare
`網站` · 瀏覽器（Indian Type Foundry） · 免費可商用 · 約 100 套字型、59 組配對（2026-11-14） · ⬜ 待試

**做什麼**：印度字型公司 Indian Type Foundry（ITF）的免費字型庫。可以依類別（無襯線、襯線、粗襯線、展示、手寫、草書）、字重、寬度、對比、x 高度、風格個性（現代、優雅、未來感……）篩選，直接在頁面上打字預覽；另有 59 組字型搭配建議。熱門的有 Satoshi、Clash Display。

**⚠️ 注意（授權分兩種，FAQ 寫得很清楚）**
- **全部可以免費商用**：印刷、網頁、App、廣播都行，也可以拿去註冊 logo（但不能聲稱擁有那套字型）；不強制標示出處。
- **Closed Source 字型**（例如 Satoshi、Clash Display）用 ITF 的 Free Font License：
  - **不能把字型檔轉給客戶、外包或其他公司**，對方要自己去 Fontshare 下載並同意授權；
  - 同一個組織內、同一專案的成員可以互相分享；
  - **不能放到自己的網站或 repo 讓人下載**，從第三方網站下載的也不算有授權。
- **Open Source 字型** 用 SIL OFL，可以自由轉發，但要遵守 OFL。
- **實務上**：把字型檔 commit 進要公開的 repo 前，先看那套是哪一種授權。FAQ 也提到可以透過它的 API 引用字型，同樣要同意授權條款。
