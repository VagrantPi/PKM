> 主題索引（MOC）：當你想「聽懂別人、清楚表達自己、化解衝突、贏得好感、在職場被看見」這類人際情境時，從這裡進入。六本書角度互補：《溝通的藝術》給全景框架、《非暴力溝通》給表達句型、《好好說話第一步》專攻傾聽、《如何正確吵架》處理伴侶衝突、《人性的弱點》談影響與好感、《內向者溝通聖經》給內向者職場策略。

## 👂 傾聽與理解對方
- 想真正接住對方、避免越聽越想反駁 → [[工具-反應式傾聽]]（入口）
- 急著給建議或分享自己時，先擱置自我 → [[工具-擱置自我傾聽]]
- 用四要素同理體會並反饋 → [[工具-同理傾聽]]
- 不確定自己對對方的解讀時先查證 → [[工具-知覺檢核]]

## 🗣 清楚表達自己與情緒
- 想請對方改變又不想像指責 → [[工具-我訊息清晰表達]]
- 觀察—感受—需要—請求四步句型 → [[工具-非暴力溝通四步]]
- 氣到想反擊時，把憤怒轉成需要 → [[工具-充分表達憤怒]]
- 對自己說話：用選擇取代「不得不」、自我寬恕 → [[工具-選擇做取代不得不]]

## 🔥 衝突與批評
- 被批評想反擊時，改用不防衛回應 → [[工具-對批評不防衛回應]]
- 僵持只覺得「我對他錯」時，站五個立場 → [[工具-枕頭法]]
- 伴侶吵架的公平規則 → [[工具-公平吵架七守則]]
- 找出爭吵表面下真正的渴望 → [[工具-挖出爭吵底層渴望]]
- 吵完後重新連結 → [[工具-修復裂痕]]
- 情緒被劫持時先喊停冷靜 → [[工具-叫暫停冷靜]]
- 辨識並管理自己被觸發的過度反應 → [[工具-管理情緒反應性]]
- 想抱怨/請求又不想引發爭吵 → [[工具-抱怨而不引發爭吵]]
